# 五行落生活对照表（喜用/忌 → 行为 / 环境 / 行业相性）

> 用途：给「02 滋养你 / 消耗你」板块提供「落生活」素材，让喜用神不止停在五行名词，而是落到**具体可做的事、适合的环境、相性的行业方向**。
> 硬约束：**只给「能量相性方向」，不给「择业/投资/婚恋/健康」决定。** 这是最多人关注的部分，务必做扎实、做具体、贴到 ta 的真实场景。

## 二、AI 生成时的硬规则

1. **喜用神逐条给「落生活」**：每个喜用五行，至少给出「一个行为 + 一个环境/作息 + 一个行业方向」。例：水 → 多写多讲（行为）+ 慢一点、给自己留白（环境）+ 内容/传播/咨询（行业）。
2. **忌神逐条给「避什么」**：每个忌神，给出「容易滑向什么状态」，并给一个「替代表达」。例：忌火 → 容易急躁内耗，用「水」的慢下来替代「火」的硬扛。
3. **行业方向只讲「相性」**：用「相性偏合 / 能量上更顺 / 更适合发挥」这类词，**禁止**「你该转行 / 你适合做 XX」的指令式，**禁止**给投资建议。
4. **贴真实场景**：用户已透露职业/生活时，把五行建议「贴到 ta 的真实场景」上，别空谈五行名词。例：用户做内容/运营 → 水的「多表达多分享」正好贴 ta 的「持续输出」。
5. **喜用顺序要说清**：先讲「第一喜用（常是调候用神）」，再讲「帮身用神」；若扶抑与调候冲突，明说「调候优先」及原因，别含糊。

## 三、行业属性不是绝对的（三层属性，必须讲清）

> 用户最容易把「行业相性」理解成「我命里该做 XX 行业」——这是误读，必须主动纠正。

属性其实有三层，一层比一层贴人：

1. **行业层（最粗）**：行业整体有一个属性倾向（如互联网偏火、金融偏金、教育偏木）。**但这层最不准**——它只是统计意义上的大方向。
2. **岗位层（较准）**：同一个行业里，做不同的事属性完全不同。例：互联网（火）里——写代码偏金（逻辑、规则）、做内容偏水（表达、流动）、做品牌偏火（曝光、点燃）、做管理偏土（统筹、承载）。
3. **个人层（最准）**：同一个人，工作内容、协作模式不同，属性也不同。带团队偏土、独立深耕偏金、频繁对外沟通偏水、冲业务一线偏火。

**结论口径（照这个讲）**：

> 「行业属性只是最粗的第一层参考。真正决定能量顺不顺的，是你**每天实际在做的那件事**是什么属性——同一行里换个岗位、换个工作模式，属性可能就变了。所以这不是绝对的，更不是转行依据；它的用处是：在现有工作里，把你做的事往喜用属性的方向调一调。」

## 四、示例口径（庚金 · 身弱 · 夏月燥热）

> 下面以一个「庚金日主 · 身弱 · 夏月燥热」的盘为例，示范喜用怎么「落生活」（数据来自排盘脚本，非虚构）：

- **第一喜用 = 水（调候）**：润燥、降温、把憋着的说出来。落生活＝多表达、多分享、亲近水、往内容/传播方向引。
- **帮身用神 = 金（比劫）**：练硬技能、立住专业、讲边界。落生活＝技术/专业人设、白金色系、清爽有序的环境。
- **忌 = 火（七杀压身）**：焦虑、高压、熬夜、追热点、跟人较劲。替代表达＝用「水」慢下来、说出来，替代「火」的硬扛。
- **忌 = 木（财生杀）**：机会太多、贪多、担不动。替代表达＝学会筛选、拒绝，抓一两个重点深耕。
