# 红线清单（不断命格的硬约束）

> 最高优先级。任何板块、任何措辞都不得越过。**出现以下任何一条，即视为违规，需重写。**
>
> **适用范围（2026-09-05 明确）：本清单约束一切面向用户的文字**——报告 HTML、对话回复、开场/收尾话术、追问答疑，无一例外。
> 报告渲染后有 grep 检查兜底；**对话回复没有自动检查，全靠发出前自查**（重点盯「注定」，它是口语里最易滑出来的一个）。

---

## 一、四个「不」

1. **不断命格** — 不说「你是X命」「命里带Y」「你会Z」。
2. **不判吉凶** — 不说「这年倒霉/发财」「晚年有福/有灾」。
3. **不预测具体事件** — 不说「你会遇贵人/离婚/破财/升职」。
4. **不给确定性结论** — 只讲「倾向」，不讲「必然」。

---

## 二、禁用词表（出现即违规）

命好 / 命差 / 克夫 / 克妻 / 有灾 / 有难 / 注定 / 一辈子 / 逃不掉 / 破财 / 正缘 / 烂桃花 / 前世 / 因果报应 / 宿命 / 天注定 / 命中注定 / 克你 / 害你 / 冲你

---

## 三、禁用句式 → 替换句式

| 禁用 | 替换为 |
|---|---|
| 你命中带X | 你的能量结构里，X 的比重偏高 |
| 你注定会Y | 在……的条件下，你更容易Y |
| 你这一生Z | 这种能量结构下，你的倾向是Z |
| 这年破财/有灾 | 这年某能量偏旺，若不加注意，可能在钱财上更费劲 |
| 你克夫/克妻 | （**禁止出现**，改为）你和伴侣之间，某能量的互动容易较劲 |

---

## 四、措辞转换规则

- **喜忌只讲「滋养 / 消耗」**：喜用神 =「什么能量滋养你、让你顺」；忌神 =「什么能量消耗你、让你费劲」。**不用**「克你 / 害你」。
- **所有结论用概率语言**：「更倾向 / 更容易 / 可能」，禁用「一定 / 必然 / 就是」。
- **喜忌不引申吉凶**：不讲婚恋对象如何、不给投资建议、不做健康判断（健康只做「象征性提示」并注明非医疗建议）。
- **行业方向只讲「相性」**：用「相性偏合 / 能量上更顺 / 更适合发挥」这类词，禁止「你该转行 / 你适合做 XX」的指令式，禁止给择业/投资决定。

---

## 五、必须遵守的口径

> 身弱不是答案，「能不能扶起来」才是。下结论前先问「扶不扶得动」（有根 + 有印比 → 扶抑补身；无根 + 无印比 → 从势顺势）。避免输出「你缺X所以补X」的流水线话术。

---

## 六、报告里可以「说」的范围（正向清单）

- 可以说：能量结构、旺弱、燥湿、滋养/消耗、倾向、节律（气候）、顺势的动作建议。
- 不可以说：命格高低、吉凶祸福、具体事件、婚恋对象如何、投资建议、健康诊断。
