# 五行能量说明书

> 把你的出生时间，变成一份 5000 字的「个人使用说明书」。免费开源。

一个 AI Skill：你给出出生日期、时间、地点，它用天文历法库精确排盘，再由 AI 翻译成大白话，生成一份只属于你一个人的能量说明书。

---

## 它能给你什么

一份可读、可下载的 HTML 报告，包含：

- **你的「底子」**：日主强弱、五行多缺，一句话讲清（白话版）／附完整依据（专业版）
- **适合与避开**：适合的行业、岗位、工作方式，以及什么环境让你「回血」
- **今年的节奏**：事业 · 健康 · 感情 · 注意事项，逐年给出
- **双版本一键切换**：白话版零门槛看结论，专业版讲清「为什么」

---

## 为什么可信

- **已经过严格校验**：排盘与分析的准确性经过反复核对与测试（真太阳时校正、大运起排、喜忌取用等关键环节均有校验）。
- **计算不靠 AI 现编**：排盘、强弱、喜忌全部由脚本（天文历法库 + 真太阳时校正）算出，AI 只负责把结果翻译成人话，每个结论都能追溯。
- **有边界**：不预测吉凶、不贩卖焦虑、不说「你注定」——它是一面镜子，不是判决书。
- **隐私安全**：出生信息只存在你自己的电脑，不上传任何地方。

---

## 快速开始

1. 下载本仓库（**Code** 按钮 → **Download ZIP**，或到 Releases 页下 zip），解压后把文件夹重命名为 `wuxing-energy-report`，放进你所用 AI 工具的 skills 目录（支持 WorkBuddy、Claude Code、Codex，开箱即用，无需安装任何依赖）；
2. 想在开始前列一眼装没装全，可在 skill 目录里跑 `python3 scripts/selfcheck.py`；
3. 对 AI 说：

```
帮我看看我的能量说明书，2001年7月1日 凌晨4点55分 广东深圳 女
```

4. 得到一份专属报告，之后可以围绕它无限追问（工作、关系、节奏……）。

> 详细安装说明见 [INSTALL.md](INSTALL.md)。
